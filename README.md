# Tecnologia-e-Inova-o-no-Agro
Trabalho do Agrinho, Agro Forte: Futuro Sustentável - Tecnologia e Inovação no Agro

  #Sobre o Projeto:
O Agro Forte/Tecnologia e Inova no Agro, é um projeto do Concurso Agrinho que une tecnologia, agricultura e sustentabilidade, inspirado no estilo de jogos como Stardew Valley. A proposta é mostrar como o campo e a tecnologia podem trabalhar juntos para um futuro mais eficiente e sustentável.

  #Inspiração
Inspirado em Stardew Valley ( jogo criado em 2016 po Eric Barone, ou então ConcernedApe).

  #Tecnologias no Agro Forte
Drones agrícolas para monitoramento
Irrigação inteligente para economia de água
Cultivos mais eficientes e sustentáveis

  #Tecnologias do Projeto
HTML - CSS - JavaScript -Pixel Art

  #Objetivo
Mostrar como a tecnologia pode transformar a agricultura de forma sustentável e criativa, no caso por meio de jogos/mundo atual dos jovens
